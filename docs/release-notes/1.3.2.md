### What's changed

A maintenance release. The app's features are unchanged from v1.3.1 — this
release updates the libraries the app is built on and the tooling it is built
and tested with.

#### Changed

- The app's hosting, dependency-injection and logging libraries moved to the
  11.0.0 releases (`Microsoft.Extensions.Hosting`,
  `Microsoft.Extensions.DependencyInjection.Abstractions`,
  `Microsoft.Extensions.Logging.Abstractions`). The app still runs on .NET 10
  and still ships as a self-contained exe.
  ([#205](https://github.com/bhemsen/PodBridge/pull/205),
  [#206](https://github.com/bhemsen/PodBridge/pull/206))
- Test tooling updated: `xunit` 2.9.3, `xunit.runner.visualstudio` 4.0.1,
  `Microsoft.NET.Test.Sdk` 18.12.0 and `Microsoft.Extensions.TimeProvider.Testing`
  11.0.0 (tests only; not shipped in the exe). The full test suite still
  discovers and passes every test.
  ([#207](https://github.com/bhemsen/PodBridge/pull/207),
  [#208](https://github.com/bhemsen/PodBridge/pull/208),
  [#209](https://github.com/bhemsen/PodBridge/pull/209),
  [#210](https://github.com/bhemsen/PodBridge/pull/210))
- Build and code-scanning pipeline: `actions/setup-dotnet` 6.1.0,
  `actions/dependency-review-action` 5.0.1 and CodeQL action 4.39.1 (`init` and
  `analyze` together), all still pinned to exact commits.
  ([#202](https://github.com/bhemsen/PodBridge/pull/202),
  [#203](https://github.com/bhemsen/PodBridge/pull/203),
  [#211](https://github.com/bhemsen/PodBridge/pull/211))

Every default (Tier-1) feature keeps working with no driver and no admin, and is
unaffected by everything above.
