### What's changed

A maintenance release. The app itself is functionally unchanged from v1.3.0 —
this release refreshes the build and release tooling it is produced with.

#### Changed

- The release pipeline now uses `actions/upload-artifact` 7.0.2 and
  `actions/download-artifact` 8.0.2, both still pinned to exact commits.
  ([#197](https://github.com/bhemsen/PodBridge/pull/197),
  [#198](https://github.com/bhemsen/PodBridge/pull/198))
- Code scanning moved to CodeQL action 4.38.3 (`init` and `analyze` together).
  ([#200](https://github.com/bhemsen/PodBridge/pull/200))
- Test dependency `Microsoft.Extensions.TimeProvider.Testing` updated to 10.11.0
  (tests only; not shipped in the exe).
  ([#199](https://github.com/bhemsen/PodBridge/pull/199))

Every default (Tier-1) feature keeps working with no driver and no admin, and is
unaffected by everything above.
